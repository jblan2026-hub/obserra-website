## Mapping rules

- A Rev. 2 identifier maps to the zero-padded identifier in Rev. 3 when that identifier remains active. If the zero-padded identifier is listed as withdrawn, the record reports withdrawn rather than inventing a semantic replacement.
- Implementation trace records are inherited from the controlled Rev. 3 registry only when they explicitly list the Rev. 2 identifier. Evidence availability is not a CMMC assessment result.
- Every Rev. 2 requirement remains not_assessed until all applicable NIST SP 800-171A Jun2018 determination statements are evaluated for the approved CMMC Assessment Scope.
- Active Rev. 3 requirements without a same-number Rev. 2 requirement remain visible as Rev. 3-only engineering requirements.
