## Permanent evidence-based acceptance rule

The owner requires every claimed result to be provable by direct evidence. This is now a hard governance rule for the entire Academy program.

A plan, outline, manuscript, manifest, checklist, activity map, script, placeholder, mockup, file name, package label, expected runtime, intended configuration, or successful ZIP creation is NOT proof that a course requirement is complete.

No course, module, media asset, SCORM package, PowerPoint, handout, reference set, assessment, completion rule, certificate, accessibility control, LearnWorlds activity, runtime duration, mobile/desktop experience, or publication state may be called complete, validated, accepted, production-ready, or working unless the claimed result has direct evidence.

Examples of required proof include, as applicable:

- actual generated file present and readable;
- clean extraction and hash verification;
- actual PowerPoint/PDF/handout files, not descriptions of them;
- SCORM package files with valid manifests and launch content;
- launch/completion test evidence for SCORM;
- actual video file and media metadata proving requested resolution/duration;
- actual captions/transcript aligned to the final media;
- owner approval for exact face, voice, title, brand, and professional quality;
- actual LearnWorlds activity existence and launch evidence;
- learner-journey evidence proving completion logic and 80 percent assessment behavior;
- actual certificate issuance evidence;
- accessibility test evidence;
- desktop/mobile test evidence;
- measured instructional runtime or a defensible activity-duration evidence matrix matching the website catalog duration;
- current authoritative-source verification;
- screenshots, exports, logs, provider results, validation reports, hashes, or other direct artifacts supporting the specific claim.

If direct evidence does not exist, the state must be `NOT PROVEN`, `PENDING`, `BLOCKED`, or `FAILED`, not complete.

## Website duration and instructional alignment

The website catalog is authoritative for course level and nominal instructional duration. Foundation courses are 2.5 hours and use the governed module timing pattern defined in `app/academy/courseData.ts` (24, 26, 28, 30, and 42 minutes). Higher course levels use the longer website-defined durations and module timing patterns.

A course cannot claim alignment merely because its manifest says 2.5 hours. The content/activity evidence must reasonably support the advertised duration through substantive instruction, narrated/video material, readings, scenarios, exercises, guided practice, knowledge checks, and applied work.
