# Obserra Pollo Website Interactive Ads Production Pack

Owner: OBSERRA EXECUTIVE PROTECTION & INTELLIGENCE LLC

Status: Production prompts and website placements implemented; Pollo renders pending owner generation and approval

Effective date: 2026-08-11

## Purpose

This pack defines the first official-brand Pollo AI assets for `www.obserrallc.com`. The assets replace selected static homepage images with controlled cinematic loops and add four website campaign advertisements.

The website implementation is feature flagged. Until approved MP4 files are present, the existing official Obserra images remain visible as poster fallbacks.

## Official brand direction

Every asset must use:

```text
Dark navy
Black
Gold
White
Restrained holographic blue
Premium enterprise documentary realism
Motivated practical lighting
Controlled cinematic camera movement
Clean negative space for website copy
```

Required controls:

1. Use the official Obserra logo only in the website or controlled postproduction layer.
2. Do not ask Pollo to generate the Obserra logo.
3. Do not generate course titles, statistics, legal claims, captions, or critical text inside scenes.
4. Do not use personal photographs or unapproved likeness material.
5. Do not use third party logos, recognizable public figures, or identifiable company branding.
6. Do not use excessive cyberpunk neon, generic server rooms, hooded hackers, morphing anatomy, or science fiction gimmicks.
7. Use realistic people, behavior, environments, lighting, devices, and operational movement.
8. Maintain editorial head and tail handles for each generated shot.

## Website integration behavior

The website implementation provides:

1. Static official Obserra poster fallback by default.
2. Feature flag activation only after approved MP4 files are present.
3. Muted autoplay when the asset is visible.
4. Automatic pause when the asset leaves the viewport.
5. User controlled pause and play.
6. Reduced motion fallback to the static poster.
7. Video error fallback to the static poster.
8. Official logo applied as a website overlay rather than generated inside the video.
9. Responsive desktop, tablet, and mobile layouts.
10. Direct campaign links to EIOS, Academy, Protection and Intelligence, and Cybersecurity Advisory.

Feature flag:
