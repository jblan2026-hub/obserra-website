The Class C and Class A licenses are not, by themselves, treated by this repository as authority to issue the 40-hour Class CC Private Investigator Intern training certificate.

Before any license-qualifying private-investigator course is offered, Obserra must establish and document the applicable Florida training-school / Department of Education authorization pathway, required curriculum and examination rules, instructor qualifications, certificate controls, recordkeeping, and any FDACS interfaces.

Until that regulatory path is verified and the required approvals are active, the website must not claim that an Obserra investigative course satisfies the Class CC or Class C licensing training requirement.
